## 连通的用户流程与边界

本地 PDF 上传后，Docling 保留正文、页码、表格结构和图表裁剪；解析完成后单独建立索引，只有 READY 版本参与 BM25 与 multilingual-e5-small 混合检索。工作台按对话保存所选知识库，提交轮次时冻结库范围、索引 revision 和模型配置。模型动作只接受问题，不能扩大库范围或指定资源路径。

问答 API 和工作台共用证据验证。答案完成引用核验后分段展示，状态包含排队、检索、生成和验证；这不是原始 token 流，也不展示私有思维链。引用可打开静态 PDF 页、结构化表格和图片裁剪。读取核对所属关系、实际引用和磁盘哈希；重建/删除后历史答案、旧预览与 SSE 重放失效。真实 UI 已覆盖六条命中、预览像素、切换/刷新恢复、三轮撤销、旧 PDF 409 和窄屏。

文献知识库不替代 counts，不授予统计执行权限；GEO 和 bulk RNA-seq 的原审批流程保留。API 可独立调用 search/ask，问答复用已配置模型。不存在自动运行文献或模型提供的任意代码的入口。

## 已知限制与后续判断

- 图片检索仅依据图注/OCR，`visual_semantics=not_performed`；显示图表不表示模型能够读出柱高或精确数值。
- 三份短合成英文 PDF 只能证明实现连通，不能代表任意论文的解析、召回和回答正确率。双栏顺序、OCR 空格、跨页表格分片与图注关联仍需人工对照原 PDF；图像检索对措辞敏感。
- 混合排序没有通用语义正确阈值；存在近邻命中不代表问题必有答案。引用归属和存活校验不证明答案准确解释论文。
- 真实供应商问答尚未联调，未验收用户实际文献的语义质量。无视觉理解或跨页表格自动合并的完成声明。
- 本地服务使用单实例。子进程环境、网络及资源限制不等同操作系统沙箱；已经下载到用户机器的原 PDF 无法撤回。
