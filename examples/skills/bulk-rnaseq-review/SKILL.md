# Bulk RNA-seq review notes

Use this Skill as explanatory context only. It does not execute Python, R, shell
commands, or MCP tools, and it is not statistical evidence. The existing
DESeq2 plan, deterministic QC, and researcher approval remain authoritative.

Before approving a plan, check the numerator/denominator direction, biological
replicates, raw-count requirement, and any warnings in the generated report.
